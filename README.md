# DNA Sequence & GC-Content Analyzer

A lightweight bioinformatics tool written in Python to analyze raw DNA sequences, calculate nucleotide frequencies, and compute the GC content percentage.

## Biological Importance
GC-content is a critical metric in molecular biology:
- Influences the thermal stability and melting temperature (Tm) of DNA.
- Essential for designing PCR primers and analyzing genomic stability.

## Features
- Cleans and formats raw DNA input.
- Counts frequencies of Adenine (A), Thymine (T), Guanine (G), and Cytosine (C).
- Computes overall sequence length (bp) and GC percentage.

## Usage
Run the script using Python:
```bash
python dna_analyzer.py
